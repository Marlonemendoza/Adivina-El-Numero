# 📱 Adivina El Número (Android App)

Aplicación móvil desarrollada en **Android Studio** utilizando **Kotlin**, diseñada para ofrecer una experiencia de juego interactiva con una interfaz moderna y atractiva.

---

## 🚀 Características Principales
* **Pantalla de Inicio de Usuario:** Registro y bienvenida personalizada para el jugador.
* **Lógica de Juego Dinámica:** Mecánica de adivinanzas con retroalimentación en tiempo real.
* **Diseño Visual Moderno:** Uso de gradientes animados, bordes redondeados personalizados y soporte para temas oscuros (*Dark Mode*).
* **Compatibilidad:** Desarrollado bajo los estándares modernos de Android utilizando componentes de XML y Kotlin.

---

## 🛠️ Tecnologías y Herramientas Utilizadas
* **Lenguaje:** [Kotlin](https://kotlinlang.org/)
* **Entorno de Desarrollo:** [Android Studio](https://developer.android.com/studio)
* **Control de Versiones:** Git y GitHub
* **Diseño de Interfaz:** Material Design, XML Layouts y Drawables personalizados.
